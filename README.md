# Генератор рецептов Chef Claude

Веб-приложение для генерации рецептов на основе имеющихся ингредиентов с использованием искусственного интеллекта.

## Описание

Chef Claude - это React-приложение, которое помогает пользователям находить рецепты блюд на основе имеющихся у них ингредиентов. Приложение использует модель AI Llama 3 через OpenRouter API для генерации персонализированных рецептов.

## Функциональность

- Добавление ингредиентов в список
- Генерация рецепта на основе введенных ингредиентов

## Технологии

- React
- Vite
- OpenRouter API (модель meta-llama/llama-3-8b-instruct)

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Roman-oryol/chef-claude.git
cd chef-claude
```

2. Установите зависимости:

```bash
npm install
```

3. Создайте файл с переменными окружения `.env` и добавьте ваш API ключ OpenRouter:

```
VITE_OPENROUTER_API_KEY=ваш_api_ключ
```

4. Запустите приложение в режиме разработки:

```bash
npm run dev
```

## Использование

1. Введите имеющиеся у вас ингредиенты в поле ввода
2. Нажмите кнопку "Добавить ингредиент" для каждого ингредиента
3. После добавления всех ингредиентов нажмите "Получить рецепт"
4. Дождитесь генерации рецепта искусственным интеллектом
5. Следуйте предложенному рецепту!
